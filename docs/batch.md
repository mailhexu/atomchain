# Batch Trajectory Processing

Calculate energy, forces, and stress for all structures in a trajectory file using machine learning potentials. Ideal for processing datasets generated by `mlrattle` or other trajectory sources.

## CLI Usage

```bash
# Basic batch processing
mlbatch input.traj --calc chgnet -o results.traj

# Process with MACE
mlbatch dataset.traj --calc mace -o with_properties.traj

# Quiet mode (no progress output)
mlbatch input.traj --calc chgnet -o results.traj --quiet

# Verbose mode (detailed output)
mlbatch input.traj --calc chgnet -o results.traj --verbose
```

### Options
- `trajectory` - Input trajectory file (POSCAR, CIF, XYZ, .traj, etc.)
- `--calc, -c` - Calculator: `chgnet`, `mace`, or any ASE calculator name
- `--output, -o` - Output trajectory file (default: `batch_results.traj`)
- `--verbose, -v` - Show detailed progress information
- `--quiet, -q` - Suppress all output except errors

## Python API

```python
from atomchain.batch import calculate_trajectory_batch
from ase.io import read

# Basic batch processing from file
results = calculate_trajectory_batch(
    'dataset.traj',
    calculator='chgnet',
    output='results.traj'
)

# Process with custom calculator instance
from chgnet.model import CHGNet
calc = CHGNet.load()
results = calculate_trajectory_batch(
    'dataset.traj',
    calculator=calc,
    output='results.traj'
)

# Process list of structures directly
structures = read('input.traj', ':')
results = calculate_trajectory_batch(
    structures,  # Pass list directly
    calculator='mace',
    output='results.traj'
)

# Access calculated properties
for atoms in results:
    print(f"Energy: {atoms.get_potential_energy()} eV")
    print(f"Forces shape: {atoms.get_forces().shape}")
    print(f"Stress: {atoms.get_stress()}")
```

### Parameters
- `trajectory` - Input trajectory file path or list of ASE Atoms objects
- `calculator` - Calculator instance or string name ('chgnet', 'mace', etc.)
- `output` - Output trajectory file path (default: `'batch_results.traj'`)
- `verbose` - Show detailed progress (default: `False`)
- `quiet` - Suppress all output (default: `False`)

### Returns
List of ASE Atoms objects with calculated properties attached

## Workflow Integration

### Complete Pipeline: Generate → Calculate → Analyze

```python
from atomchain.rattle import generate_rattle_dataset
from atomchain.batch import calculate_trajectory_batch
from ase.io import read
import numpy as np

# Step 1: Generate rattled structures
print("Generating structures...")
traj_path = generate_rattle_dataset(
    'POSCAR',
    n_struct=100,
    stdev=0.05,
    supercell=[2, 2, 2],
    output='dataset.traj'
)

# Step 2: Calculate properties in batch
print("Calculating properties...")
results = calculate_trajectory_batch(
    traj_path,
    calculator='chgnet',
    output='dataset_with_properties.traj',
    verbose=True
)

# Step 3: Analyze results
energies = [atoms.get_potential_energy() for atoms in results]
forces = [atoms.get_forces() for atoms in results]

print(f"\nDataset statistics:")
print(f"  Structures: {len(results)}")
print(f"  Energy range: {np.min(energies):.3f} to {np.max(energies):.3f} eV")
print(f"  Mean |force|: {np.mean([np.linalg.norm(f) for f in forces]):.3f} eV/Å")
```

### Command-Line Pipeline

```bash
# Generate dataset
mlrattle POSCAR --nstruct 100 --stdev 0.05 --supercell 2,2,2 -o dataset.traj

# Calculate properties
mlbatch dataset.traj --calc chgnet -o results.traj --verbose

# Analyze (Python script or interactive session)
python analyze_results.py results.traj
```

## Calculator Support

The tool supports any ASE-compatible calculator:

**Built-in shortcuts:**
- `chgnet` - CHGNet universal potential
- `mace` - MACE universal potential
- `emt` - Effective Medium Theory (testing only)

**Custom calculators:**
```python
from some_package import SomeCalculator

calc = SomeCalculator(param1=value1, param2=value2)
results = calculate_trajectory_batch(
    'input.traj',
    calculator=calc,  # Pass configured instance
    output='results.traj'
)
```

## Performance Notes

**Calculator Reuse:**
The calculator is initialized once and reused for all structures, which is efficient for most ML potentials.

**Progress Reporting:**
- Default: Shows progress for each structure with calculated energy
- `--verbose`: Shows detailed timing information and ETA per structure
- `--quiet`: No output except errors

**Example output (default mode):**
```
[Batch] Processed structure 1/100 (E=-3.664310 eV)
[Batch] Processed structure 2/100 (E=-3.663998 eV)
...
```

**Example output (verbose mode):**
```
[Batch] Processed structure 1/100 (E=-3.664310 eV, 1.81s, ETA: 7.2s)
[Batch] Processed structure 2/100 (E=-3.663998 eV, 0.03s, ETA: 2.8s)
...
```

**Memory Management:**
Structures are processed sequentially to minimize memory usage. For very large trajectories, results are written incrementally to the output file.

## Error Handling

If calculation fails for specific structures:
```python
results = calculate_trajectory_batch(
    'input.traj',
    calculator='chgnet',
    output='results.traj'
)

# Failed structures are skipped and reported
# Check console output for: "Failed structures: [12, 45, 67]"
```

The function continues processing remaining structures and returns only successful results.

## Output Format

Output trajectory files contain:
- All original structure information (positions, cell, symbols)
- Calculated properties attached to each Atoms object:
  - `atoms.get_potential_energy()` - Total energy (eV)
  - `atoms.get_forces()` - Atomic forces (eV/Å)
  - `atoms.get_stress()` - Stress tensor (eV/Å³)

Properties are stored in ASE's standard format and can be accessed using standard ASE methods.

## Examples

### Process Specific Subset
```python
from ase.io import read, write
from atomchain.batch import calculate_trajectory_batch

# Load full trajectory
structures = read('large_dataset.traj', ':')

# Process first 100 structures
subset = structures[:100]
results = calculate_trajectory_batch(
    subset,
    calculator='chgnet',
    output='subset_results.traj'
)
```

### Multiple Calculators
```python
# Compare different calculators
for calc_name in ['chgnet', 'mace']:
    results = calculate_trajectory_batch(
        'dataset.traj',
        calculator=calc_name,
        output=f'results_{calc_name}.traj',
        quiet=True
    )
    print(f"{calc_name}: {len(results)} structures processed")
```

### Filter by Energy
```python
from atomchain.batch import calculate_trajectory_batch

results = calculate_trajectory_batch(
    'dataset.traj',
    calculator='chgnet',
    output='all_results.traj'
)

# Filter low-energy structures
low_energy = [
    atoms for atoms in results 
    if atoms.get_potential_energy() < -3.5
]

write('low_energy_structures.traj', low_energy)
print(f"Found {len(low_energy)} low-energy structures")
```

## Notes

- Input can be any ASE-readable format (.traj, POSCAR, CIF, XYZ, etc.)
- Output format determined by file extension (default: .traj)
- Calculator instance is reused for efficiency
- Failed calculations are reported but don't stop processing
- Progress updates help track long-running calculations
- Use `--quiet` for scripting and automation
